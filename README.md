# GitHub Profile Viewer

Projeto desenvolvido para consulta de perfis do GitHub utilizando a API oficial da plataforma. O sistema permite a visualização consolidada de informações de usuário e seus repositórios mais recentes.

Este projeto integra a formação Fullstack do DevQuest, servindo como exercício prático para consolidação de conhecimentos em JavaScript, consumo de APIs REST e manipulação do DOM.

## Funcionalidades

- **Busca de Usuários:** Interface de busca por nome de usuário com validação de entrada.
- **Informações do Perfil:** Exibição de avatar, nome, bio, seguidores e seguindo.
- **Listagem de Repositórios:** Exibição dos 10 repositórios mais recentes, incluindo métricas de stars, forks, watchers e linguagem predominante.
- **Interface Responsiva:** Layout adaptável para diferentes dispositivos e resoluções.
- **Tratamento de Erros:** Feedback visual para usuários não encontrados e campos de busca vazios.

## Tecnologias Utilizadas

- **HTML5 e CSS3:** Estruturação e estilização com foco em responsividade.
- **JavaScript (ES6+):** Implementação de lógica assíncrona (Async/Await), módulos (ESM) e manipulação dinâmica do DOM.
- **GitHub API:** Integração com a API REST para recuperação de dados em tempo real.

## Como Executar

1. Clone o repositório para sua máquina local.
2. Acesse o diretório do projeto.
3. Abra o arquivo `index.html` em seu navegador ou utilize um servidor local (como a extensão Live Server).
